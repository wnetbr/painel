Primeira instalação no GitHub

  1. Publique este index.html com o GitHub Pages.

    No repositório, abra Settings → Pages e escolha a origem da publicação. Acesse o endereço HTTPS gerado.

  2. Crie ou escolha um projeto no Google Cloud e ative a Google Docs API.

    Em Google Auth Platform, configure Branding e Audience. Para uso pessoal em teste, adicione seu e-mail como usuário de teste.

  3. Em Data Access, configure o escopo https://www.googleapis.com/auth/documents.

    Ele permite ler e editar documentos em que sua conta já tem permissão. O painel só chama os três documentos da Wnet. O Google pode exigir verificação para disponibilizar o OAuth publicamente.

  4. Em Clients, crie um cliente OAuth do tipo Aplicativo da Web.

    Em Origens JavaScript autorizadas, cadastre a origem do site, sem o caminho do repositório. Exemplo: https://seuusuario.github.io. Origem deste painel: .

  5. Copie o ID do cliente para o campo acima, salve e clique em Conectar Google.

    Autorize a leitura e edição com a conta proprietária dos documentos. Não é necessário colocar um segredo de cliente no HTML.

Os links não aparecem nas telas de gerenciamento, mas seus identificadores podem ser vistos no código de um site estático. A proteção contra alterações depende das permissões do Google: mantenha a edição restrita à sua conta. Não altere a permissão de leitura sem verificar como o aplicativo lê os documentos.
Como a sincronização funciona

O painel lê os documentos diretamente pela API do Google Docs após a autorização. As edições ficam pendentes até você salvar e confirmar. Ao salvar, o painel verifica a revisão e impede a sobrescrita de alterações externas. Se uma edição externa chegar enquanto houver um rascunho, o rascunho é preservado e o salvamento é bloqueado até você descartar e recarregar.

Com “Manter conectado neste navegador” ativado, a autorização e sua validade ficam armazenadas neste navegador, neste endereço do painel. Ao reabrir, uma autorização válida é reutilizada e os documentos são consultados novamente. Em outro navegador ou dispositivo, é preciso conectar. Ao expirar, clique em Reconectar Google; o Google poderá pedir confirmação. Sair apaga a autorização salva. Limpar os dados do site ou usar navegação anônima também pode impedir a lembrança do acesso. O ID público do cliente e as preferências ficam salvos no navegador. Fechar ou recarregar a página perde os rascunhos. Este painel não modifica o APK nem garante um prazo para o aplicativo consultar os documentos.
